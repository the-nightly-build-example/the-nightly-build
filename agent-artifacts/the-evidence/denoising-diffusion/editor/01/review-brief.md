## Recent-pattern notes (compare the draft's edges, dek, and headings against these)
House-wide habits recurring across recent 2026-08-29 pieces:
- "Why this matters" openers that END by telling the reader "By the end you will
  know / be able to …". Cut or recast if present; the takeaway should resolve the
  opener's setup instead.
- Generic second-person everyday-scene openers used as a reflex.
- Deks built as a two-clause "and" contrast or a comma-triad ("A, B, and C").
  Check the dek against spec/headlines.md's banned molds.
- Section headings as full declarative sentences all built the same way, some
  joined by comma+"and".
Series-specific: avoid the recent the-evidence headline shape "Tested on X…, Y now
Z" (then/now template) and a generic "The paper convinces without proving"-style
heading. Headings should be in this paper's own nouns; a reader skimming only the
headings should reconstruct THIS argument.
